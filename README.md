# leandromoreira.pt

Site pessoal. HTML/CSS/JS puro, sem build. Publicado via GitHub Pages.

- **Retrato ASCII:** coloca a tua foto como `photo.jpg` na raiz. Se não existir, usa `gato.png`.
- **Testar localmente:** `python3 -m http.server` e abre http://localhost:8000 (o retrato não funciona abrindo o ficheiro diretamente).
- **Easter eggs:** terminal (`help`), clicar no retrato, código konami.
